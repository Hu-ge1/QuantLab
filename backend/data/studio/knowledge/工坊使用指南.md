# QMT 策略工坊 · 使用指南

## 一、这套工具是什么

本地运行的「策略生成 + QMT 桥接可视化」一站式工具,六个页面:

| 页面 | 作用 |
|---|---|
| 策略生成 | 描述需求 → 大模型生成可直接粘贴进 QMT 的策略代码 |
| 模板库 | 15 个常用策略骨架,填参数即生成需求 |
| QMT 可视化 | 实时看板:行情/持仓/委托成交/情绪/信号/下单 |
| QMT 知识库 | QMT 接口与最佳实践文档 |
| 历史记录 | 每次生成自动存档,可载回修改 |
| 设置 | API Key、风控、局域网、情绪统计等 |

## 二、生成策略的标准流程

1. 「策略生成」页:自由描述,或从「模板库」选模板填参数
2. 选目标形态(**大QMT内置策略**推荐)/运行模式(**回测优先**推荐)/资金与周期
3. 点生成 → 流式输出 → 系统自动**静态质检**(语法 + QMT 3.6 兼容),有问题自动修复
4. 检查「逻辑与参数」标签页的说明与风险点
5. 点「写入 QMT」(或勾选自动写入)→ 代码进 QMT 并注册到【我的策略】
6. 在 QMT 中对该模型跑回测,确认无误再考虑实盘

需要改动时,直接在「在此版本上继续修改」里用自然语言描述,支持无限迭代,每轮都有与上一版的代码差异可查。

## 三、实时看板(桥接)

1. 「QMT 可视化」页 → 一键写入并注册「QMT可视化桥接」策略
2. 打开 QMT → 模型研究 → 我的策略 → QMT可视化桥接 → **实盘模式**选择资金账号运行
3. 页面每 2 秒刷新:账户资金、自选行情、持仓盈亏、当日委托/成交、市场情绪(涨停/跌停/涨跌家数)
4. **盯盘雷达**:自选股 触板/开板/急拉/跳水 自动推送到「策略信号流」,支持提醒音与桌面通知
5. K线:选代码与周期加载(经桥接策略从 QMT 拉取),带均线与十字光标;「当日分时」用累积 tick 绘制
6. 下单:默认禁止。需要时打开「允许下单」→ 填代码/方向/价格/股数 → 二次确认 → 服务端风控校验(单笔上限/每日次数/白名单/交易时段)→ 桥接策略在 QMT 内委托

## 四、安全机制

- 服务只监听本机;开启局域网后建议设置访问密码
- 桥接数据通道使用随机 token 鉴权
- 下单默认关闭;服务端强制:交易时段校验、单笔股数上限、每日次数上限、白名单
- 覆盖保存策略前自动备份旧版到 `backups/`
- 生成的策略默认实盘关闭、只打信号,必须人工确认后才可能真实委托

## 五、常见问题

- **桥接显示未连接?** 确认 QMT 里的桥接策略在运行、本工具开着;每天收盘后桥接推送会停止属正常
- **下单被拦截?** 检查:允许下单开关、交易时段(周末/午休/收盘拦截)、单笔/每日限额、白名单
- **K线加载超时?** 桥接不在线时无法拉取;先确认桥接状态灯
- **模型列表里没有新策略?** 重启 QMT 客户端;或设置页点「重新同步注册」
